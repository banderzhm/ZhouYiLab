# 大六壬分析算法与输出契约

## 一、职责边界

大六壬排盘层负责月将、占时、天地盘、天将盘、四课、三传、课式与神煞等课盘资料；分析层只消费排盘结果，不重新起课，不复制干支基础规则。

分析采用“大六壬八门—主客—发用—三传—类神—课体—应期”的体系，不复用八字扶抑、喜忌评分或六爻世用评分。课中的制碍与救应分别保留，不以单一分数相互抵销。

控制器只负责编排输入、可选真太阳时修正、排盘和调用分析入口；中文文本与 JSON 由 Presenter 生成。

## 二、分析顺序

1. 记录占问门类、占问原文、本命、行年及缺失输入；
2. 读取占时、月将、日辰、昼夜贵人和旬空；
3. 逐宫分析天地盘上下支神的生克、刑冲、六合、六害与半合；
4. 分析四课上下生克、六亲、天将和发用来源；
5. 识别九宗门，保留取传候选及择用依据；
6. 分析初传发端、中传移易、末传归计及传间递生递克；
7. 联查三传落宫、三传与四课、四课彼此的生克刑冲合害、半合与三合；
8. 按占问策略选择类神，检查类神入课、入传、临盘、乘将、空破墓绝；
9. 分析八门、本命和行年对公共课象的变易；
10. 匹配课体与毕法结构，课体只在成立条件齐备时输出；
11. 按占类筛选相关神煞，神煞只作课传取象佐证；
12. 给出值、冲、合、出空、填实等应期候选；
13. 分列生扶救应与克制阻隔，最后形成总断和复核项。

## 三、八门输出

| 八门 | 课中对象 | 报告职责 |
|---|---|---|
| 先锋门 | 占时 | 眼下先兆、迟速、是否与发用同临 |
| 值事门 | 月将 | 当令气象及月将所临 |
| 外事门 | 日干、一二课 | 求测方、外部状态与主动行为 |
| 内事门 | 日支、三四课 | 对方、宅舍与内部情状 |
| 发端门 | 初传 | 事情起因和第一步 |
| 移易门 | 中传 | 中途变化和转折 |
| 归计门 | 末传 | 事情归宿和结果 |
| 变体门 | 本命、行年 | 公共课象落实到具体求测者后的变化 |

本命或行年未提供时，变体门必须明确标为“未提供”，不得猜测。

本命、行年一经提供，须先按其地盘本宫取得所乘天盘上神，再取上神所乘天将、
对日干六亲及空亡，最后逐一分析该上神与初、中、末传的生克、刑冲、六合、六害
和半合。报告须分别列明“本支空亡”与“上神空亡”，不得只回显两个输入地支。

## 四、类神策略

类神采用策略模式，不同占类独立配置：

| 占类 | 主类神 | 辅助取象 |
|---|---|---|
| 求财 | 日财 | 青龙、财爻所临天地盘及三传 |
| 功名事业 | 日官鬼 | 贵人、青龙、日禄、父母文书 |
| 婚姻 | 男占妻财、女占官鬼 | 六合、天后及干支主客 |
| 疾病 | 官鬼为病 | 子孙为医药，兼察白虎、天医 |
| 官讼 | 官鬼 | 勾陈、朱雀、主客强弱 |
| 考试 | 父母 | 朱雀、贵人、旬奇、日德 |
| 消息文书 | 父母 | 朱雀、信神 |
| 寻人失物 | 按人物身份或财爻选取 | 玄武、驿马、方向与空亡 |

调用方显式指定类神时优先采用人工指定，并在报告中保留该来源。

## 五、发用证据

三传排盘层最终应提供结构化 `FaYongTrace`，至少包含：

- 去重前后四课候选；
- 下贼上、上克下的位置；
- 比用阴阳筛选；
- 涉害深浅和孟仲季比较；
- 遥克、昴星、别责、八专、伏吟、返吟的成立条件；
- 最终发用及被排除候选的原因。

分析层不得仅凭“涉害”“见机卦”等中文字符串反推完整取传过程。现阶段字符串转换只作为兼容层。

## 六、课传判断原则

- 四课先定干支主客，再看上下生克、脱耗、比和及刑冲合害；
- 初传主发端，中传主移易，末传主归计；
- 三传须检查递生、递克、回生、回克、进退连茹、间传、三合、三会、三刑和回环；
- 天地盘逐宫、四课彼此及四课与三传必须使用同一套地支关系规则，允许生克、刑冲、六合、六害、半合等关系并存；
- 三合须辨三传自成局、四课上神成局和四课三传跨层补局；天地盘十二支俱全，不得脱离具体落宫机械拼局；
- 空亡表示课象先虚或暂不落实，不直接等同于绝对不成；
- 天将必须与乘神、六亲、占类合参，不以“吉将必吉、凶将必凶”机械判断；
- 课体和神煞不得越过四课三传单独定论；
- 吉象、凶象和救应分别输出，不压成单一数值。

## 七、应期口径

应期以候选形式给出，并保留推导依据：

- 发用值期主事情发动；
- 发用见合则候冲开，发用见冲则候合住；未见合冲时可候冲动；
- 中传值期主过程转折；
- 末传值期主事情归结；
- 空亡待出空或填实；
- 合局可候冲开，冲动可候合住；
- 入墓可候冲墓、开墓；
- 驿马、占时、月将和本命行年只在与类神或课传发生作用时采用；
- 必须结合所占事情的时间尺度，不从支神直接承诺唯一日期。

报告固定输出五级候选，按 `1—5` 连续编号：发用落实、发用合冲触发、中传移易、末传归计、成局或半合补齐。完整三合取旺神为聚气候选；半合取所缺支为补齐候选。

每个候选不得只列一个地支，必须同时输出：应期法、所应阶段、建议候期层级、迟速、触发条件、主要应象、限制条件、排序依据和可追溯证据。迟速按以下层次判断：

1. 支神旬空，或发用被合、受冲而尚未解除时，先标“待时”；
2. 发用、类神临日辰或占时，且不空不受阻时，可标“速”；
3. 月令旺相者较速，休囚死者较迟；
4. 驿马同临仅说明动中易应，不得越过空亡和合冲条件直接断速；
5. 初传验发端，中传验移易，末传验归计，三者不得混成同一应象；
6. 未提供明确占限时，只给“短占候时日、长占兼候月”的层级提示，不推造唯一公历日期。

半合出现“所缺支”时必须继续追踪，不能只输出一个支名：

- 该支作为天盘支神所临的地盘宫；
- 该支作为地盘本宫时，其上所乘天盘支神；
- 是否出现于四课上神、四课下神或初中末传；
- 是否与月建、日辰、占时或月将同支；
- 是否旬空；
- 属于课传内部已经出现、时令外部可补，还是课传与时令均未见；
- 即使支神出现，仍须复核旺衰、冲散和空破，不得机械判为已经成局。

## 八、模块结构

```text
src/da_liu_ren/
├─ da_liu_ren_types.cppm                     大六壬领域枚举
└─ analysis/
   ├─ da_liu_ren_analysis_contract.cppm      稳定输入输出契约
   ├─ da_liu_ren_analysis.cppm/.cpp          Facade 分析入口
   ├─ da_liu_ren_lei_shen.cppm/.cpp          Strategy 类神策略
   ├─ da_liu_ren_structure.cppm/.cpp         四课、三传、八门、应期
   └─ da_liu_ren_analysis_presenter.cppm/.cpp 中文 TXT 与 JSON
```

后续扩展课体、毕法、专项占类时，应增加独立规则模块，不得把定义表和展示文案堆入统一入口或控制器。

## 九、验收要求

- 中文报告包含完整起课资料、天地盘、四课、三传和分析，不得只输出结论；
- 天地盘、四课、三传分别使用纯表格展示，断法置于表格之后，不得把证据行插入表格；
- 天地盘必须按十二宫逐行列出地盘、天盘、天将、六亲和上下作用；
- 四课必须明确上下神、六亲、天将、生克关系和是否发用；
- 三传必须明确初中末、遁干、六亲、所临地盘、天将、旺衰、空亡和传间关系；
- 联断必须覆盖相生、相克、比和、相刑、六冲、六合、六害、半合和三合，未成立者不得伪造；
- 所有结论能回溯到规则依据；
- 本命、行年、占类缺失时不得虚构；
- JSON 与中文报告使用同一分析结果，不各自重算规则；
- Clang 与 MSVC 均通过 C++23 Modules 构建。
