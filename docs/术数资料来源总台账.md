# ZhouYiLab 术数资料来源总台账

本文登记仓库说明文档所依赖的公开资料入口、采用范围与尚待校勘事项。它不替代排盘或分析算法，也不复制站外文章；项目规则只有在能够说明采用口径、成立条件与资料链接时，才可写入实现或报告。

## 1. 使用约定

1. **排盘规则、术语资料与分析断语分开登记**：网页或古籍标题可作为检索线索，不自动成为可执行规则。
2. **同一术数可并存多套流派口径**：例如子平的格局、调候与扶抑，及盲派的宾主、体用与做功，必须由规则集或分析方法区分。
3. **网页资料只抽取条件化数据**：记录星曜、宫位、时间层、必要条件、减力或破格条件；不搬运长篇文案。
4. **报告不作确定事件承诺**：传统术数取象应说明适用条件与未决条件，不把资料中的断语写成已经发生或必然发生的现实结论。
