# 奇门遁甲排盘规则

## 资料口径与适用边界

本文以 [FateMaster 奇门遁甲大全](https://www.fatemaster.ai/guides/qimen-dunjia)、[理数奇门遁甲排盘](https://lishuhub.com/zh/qi-men-pai-pan/)、[《奇门遁甲统宗》](https://zh.wikisource.org/zh-hans/%E5%A5%87%E9%96%80%E9%81%81%E7%94%B2%E7%B5%B1%E5%AE%97)和[《遁甲演义》四库本](https://ctext.org/library.pl?if=gb&res=5785)作为公开资料入口。前两者用于现代盘面与实现口径交叉核验；后两者用于阴阳遁、三奇六仪、符使、门星神及格局条目的卷次校勘。项目必须明确采用的盘式、节气边界、正授／超接／置闰口径、局数算法、值符和值使规则；不同门派的排局不能静默混用。

网页资料只作为结构和交叉核验来源。具体排盘公式以项目实现和固定盘例回归为准；分析取象须保留占问、用神、宫门星神关系与未决条件，不将网站案例或泛化断语直接变为规则。

## 概述

奇门遁甲排盘的核心算法规则，包括：

- **定局算法**：根据节气、日期确定阴阳遁、三元、局数
- **排盘算法**：生成地盘、天盘、人盘、神盘的规则体系

## 核心概念

### 九宫（Palace）

按照后天八卦方位排列：

```
西北(6)  北(1)  东北(8)
西(7)    中(5)  东(3)
西南(2)  南(9)  东南(4)
```

### 八门（Gate）

休、生、伤、杜、景、死、惊、开为八门名目。九宫方位可作为原始门象的学习参照，
但时家盘中的门盘须依值使、时支和采用盘式移宫；不能把某门的原始宫位当作其当局
落宫，更不能仅以一个门名下定吉凶。

### 九星（Star）

天蓬、天任、天冲、天辅、天英、天芮、天柱、天心与天禽为九星名目。九星作值符的
盘面层级可由《奇门遁甲统宗》卷一校核；项目报告应保存其落宫、同宫门神、奇仪、
旺衰和占问条件，而不以“吉星／凶星／中等”三档替代组合判断。

### 八神（Spirit）

直符、螣蛇、太阴、六合、白虎、玄武、九地、九天为八神名目。八神随直符和所采用
盘式布列；其传统取象只可作为候选参看，须与同宫门、星、奇仪、格局及占问合参，
不得直接转换为确定应事。

### 阴阳遁

- **阳遁**：冬至后至夏至前使用；六仪顺布、三奇逆飞。
- **阴遁**：夏至后至冬至前使用；六仪逆布、三奇顺飞。

“顺／逆”须分别指明六仪或三奇，不能笼统写成“天干顺飞／逆飞”。九星、八门、八神另有各自的值符、值使与盘式排布规则。

### 三元

本规则集采用时家转盘常见的**符头定元**口径：先在当前节气内定位日干支所属的甲／己符头，
再以该符头所临地支定上、中、下元；不能只取当日日支而忽略日干和符头边界。

- **上元**：符头支为子、午、卯、酉
- **中元**：符头支为寅、申、巳、亥
- **下元**：符头支为辰、戌、丑、未

此处的资料依据为[《奇门遁甲统宗》所载定三元法](https://zh.wikisource.org/wiki/Page%3AGujin_Tushu_Jicheng%2C_Volume_479_%281700-1725%29.djvu/25)；交节后首个符头、超接与置闰仍必须作为独立规则集参数处理，不能由本表自动推定。


## 定局规则

### 阳遁歌

```
冬至惊蛰一七四，小寒二八五同推；
大寒春分三九六，芒种六三九是真；
谷雨小满五二八，立春八五二相随；
清明立夏四一七，九六三从雨水期。
```

### 阴遁歌

```
夏至白露九三六，小暑八二五重逢；
大暑秋分七一四，立秋二五八流通；
霜降小雪五八二，大雪四七一相同；
处暑排来一四七，立冬寒露六九三。
```

### 符头、超接与置闰

本项目的时家转盘口径须把三件事分别保存，不能只留下最终局数：

1. **正授**：节气与甲／己符头同至；
2. **超神**：符头先于节气到达，依该符头先行未来节气之上元；
3. **接气**：节气先至而符头未到，仍承前节下元，待符头到达后再接入新节上元。

《奇门遁甲统宗》卷一还把芒种、大雪之后、超至九日至十一日的闰奇作为专门条件。故实现不得仅凭“节气 + 日序”猜测置闰：排盘契约应保留 `符头`、`节气交接时刻`、`超接状态`、`是否置闰` 与 `采用盘式／流派`；未实现或输入不足时，应明确标为待定局，而非伪造常规局数。[《奇门遁甲统宗》卷一：遁甲起例、论超接之法、置闰法](https://ctext.org/wiki.pl?chapter=666094&if=gb)可直接校核本段的正授、超接和置闰术语。

同卷还列“九星值符图”“八门值使图”“值符值使诀”及四十格目录，并说明九星作值符、八门作值使。项目盘局必须分别保留：旬首、地盘值符宫、天盘值符宫、原门、值使门、值使落宫、排布方向与盘式；任何“值符吉／值使吉”类取象，都必须再检查所临宫、门星神、奇仪、格局与占问，不能把星或门的单项歌诀压成无条件结论。[《奇门遁甲统宗》卷一](https://zh.wikisource.org/zh-hans/%E5%A5%87%E9%96%80%E9%81%81%E7%94%B2%E7%B5%B1%E5%AE%97)可校核这些名目与盘面层级。

## 排盘步骤

### 基本流程

1. **确定阴阳遁**：根据节气判断
2. **确定三元**：根据当前节气内甲／己符头所临地支判断
3. **确定局数**：根据节气和三元查表
4. **排布地盘**：天干按戊己庚辛壬癸丁丙乙顺序排列
5. **确定值符和值使**：由时旬首、地盘星门及当前采用盘式推定；值符为九星，值使为八门
6. **排布天盘**：以值符加时干及采用盘式的天盘规则落位
7. **排布人盘**：八门根据时辰旋转
8. **排布神盘**：八神根据直符位置排列

### 详细规则

#### 地盘排布
地盘天干固定排列：
- 戊永远在中宫（5宫）
- 己永远在坤宫（2宫）
- 其余七干按顺序：庚辛壬癸丁丙乙分布在乾坎艮震巽离兑七宫

#### 直符直使确定
- **值符**：以时旬首所遁之仪定位地盘星门后取得；九星为值符
- **值使**：与值符配套的门盘值使；八门为值使
- **时干／时支作用**：时干用于值符加时干等天盘步骤，时支用于值使加时支等门盘步骤；具体移宫必须由所选转盘／飞盘规则集定义

#### 天盘旋转规律
- **阳遁**：六仪顺布、三奇逆飞
- **阴遁**：六仪逆布、三奇顺飞
- **天盘落位**：以值符加时干等规则推定；不得以“顺时针／逆时针”替代六仪、三奇、星盘与门盘各自的排布条件

#### 八门飞宫
八门按固定顺序飞宫：休、生、伤、杜、景、死、惊、开
- 从值使门开始，按所选盘式的值使加时支规则移宫
- 阳遁、阴遁的六仪／三奇顺逆不能直接外推为八门的单一顺逆；门盘须单独记录排布方向与采用规则集

#### 八神排布
八神从直符宫开始排列：直符、腾蛇、太阴、六合、白虎、玄武、九地、九天
- 按九宫顺序排列
- 中宫不排神

## 特殊情况处理

### 节气交接处理
- **节气当日**：以节气交接的具体时刻为准
- **早子时**：23:00-24:00 归入当日
- **晚子时**：00:00-01:00 归入次日

### 闰月处理
- **闰月排盘**：按实际月份的节气确定
- **节气不变**：闰月不影响节气的排列
- **三元计算**：以实际日干支为准

## 扩展排盘方法与待校范围

### 传统变化方法

1. **置闰、超接与拆补**：均属于定局口径的一部分；必须附符头、节气交接与流派条件，
   不能以术语名称替代实现规则。
2. **转盘、飞盘等盘式**：属于不同盘式选择；调用与报告均应显式记录，不能静默混用。
3. **数字起局、特定派别起局与其他民间法门**：本文尚无可复核的规则来源与项目契约，
   只登记为待校学习线索，不宣称已经支持。
4. **真太阳时**：仅在调用方明确提供地点且统一时间模块完成修正时采用；未提供地点时
   直接使用传入民用时间，不隐式补地点或修正时刻。
