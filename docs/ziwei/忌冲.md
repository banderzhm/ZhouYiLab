## 3 应期锁定五规则

1. **受冲者优先**  
   大限转盘先踩到“被冲之宫”的流年，事件概率最高。

2. **同类宫再恶**  
   地盘同类宫星曜与天地忌冲同见时，作为待复核的限运引动条件。

3. **天盘忌星起飞宫**  
   从大限起始年顺推：  
   - 若流年先到天盘忌星“起飞宫”先应起飞宫；  
   - 若先到受冲宫应受冲宫。

4. **事业宫主动态**  
   人盘事业宫被忌冲且天地盘结构不佳时，仅列为事业宫引动候选，不据此断定应事。

5. **单忌踩地雷**  
   人盘仅踩天盘忌入之宫尚无妨；  
   若再被流年忌冲或同类宫凶曜会合，记录叠层条件，仍须复核飞化来源和相关宫位。
