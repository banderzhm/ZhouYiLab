# 紫微斗数十二宫盘界面设计

> 设计对象：紫微斗数十二宫命盘，不包含起盘表单和右侧分析页面
>
> 参考界面：[Metis 紫微斗数在线排盘](https://metisziwei.com/chart)
> 对照日期：2026-09-11

## 1. 设计目标

十二宫盘必须同时满足“第一眼能辨宫位、第二眼能核星曜、第三眼能看运限”。界面可以参考 Metis 的 4×4 固定盘式和高信息密度，但使用 ZhouYiLab 自己的数据结构、术语和视觉规范。

核心要求：

- 十二地支固定位置，不能随数组顺序改变；
- 十二个宫格围绕中央四格排布；
- 主星、辅星、煞星、杂曜、亮度、四化必须层次分明；
- 命宫、身宫、当前大限、流年、小限不得互相覆盖；
- 中央区域只放全盘核心资料；
- 点击任一宫，可以清楚看到本宫、对宫和两个三合宫；
- 空宫借星要能看见，但不能伪装成本宫实星。

| 辰 | 中宫 | 中宫 | 酉 |
| 卯 | 中宫 | 中宫 | 戌 |
| 寅 | 丑 | 子 | 亥 |

### 2.1 CSS Grid 坐标

前端应根据宫支直接映射网格，不使用 `palaces[index]` 的数组位置猜测坐标。

```css
.ziwei-board {
  display: grid;
  grid-template-columns: repeat(4, minmax(0, 1fr));
  grid-template-rows: repeat(4, minmax(0, 1fr));
  grid-template-areas:
    "si   wu     wei    shen"
    "chen center center you"
    "mao  center center xu"
    "yin  chou   zi     hai";
  /* 参考图是纵向长盘，每宫为竖长矩形，并非正方盘。 */
  aspect-ratio: 5 / 7;
}
```

参考图中整盘约为 `586 × 820 px`，单宫约为 `146 × 205 px`。因此四列等宽、四行等高，但宫格本身是明显的竖长矩形。中央区横跨中间两列、纵跨中间两行。

### 2.2 盘框外方位标注

参考图把方位写在盘框外，不占宫格内容：

- 上边：正南方、南偏西；
- 左边由上至下：南偏东、东偏南、正东方、东偏北；
- 右边由上至下：西偏南、正西方、西偏北、北偏西；
- 下边：北偏东、正北方。

方位文字采用小号灰字，贴近对应宫位边界。它属于盘面方位辅助层，不进入任何宫位 DTO。

| 地支 | `branch_index` | `grid-area` |
| --- | ---: | --- |
| 子 | 0 | `zi` |
| 丑 | 1 | `chou` |
| 寅 | 2 | `yin` |
| 卯 | 3 | `mao` |
| 辰 | 4 | `chen` |
| 巳 | 5 | `si` |
| 午 | 6 | `wu` |
| 未 | 7 | `wei` |
| 申 | 8 | `shen` |
| 酉 | 9 | `you` |
| 戌 | 10 | `xu` |
| 亥 | 11 | `hai` |

ZhouYiLab 内部存在“寅宫为 0”的算法索引，但页面布局一律以结构化结果中的地支或 `branch_index` 为准。

## 3. 单个宫格的结构

参考图中的宫格不是四条横向信息带，而是“上方星曜列＋中部弹性留白＋底部双栏锚点”。星曜从宫格左上角开始横向铺开，每颗星自身按竖列书写；神煞和宫位信息分别压在左下、右下。

```text
┌──────────────────────────┐
│ 天 紫 天 龙 华 陀 截       │ ← 每颗星占一条竖列
│ 梁 微 相 池 盖 罗 空       │
│ 陷 闲 旺 庙 庙 庙          │ ← 亮度写在对应星名下
│      科                    │ ← 四化印章仍属该星列
│                          │
│                          │ ← 中部弹性留白
│                          │
│ 力士              12–21 │
│ 华盖                壬辰 │
│ 官符              兄弟宫 │
└──────────────────────────┘
```

命宫、身宫或当前运限宫只改变右下宫名块：

```text
│ 博士               2–11 │
│ 劫煞                癸巳 │
│ 小耗           〔命宫·命〕│
```

宫格建议使用三行网格，而不是四个固定高度分区：

```css
.ziwei-palace {
  display: grid;
  grid-template-rows: auto minmax(24px, 1fr) auto;
  min-width: 0;
  padding: 10px 8px 7px;
}

.palace-stars   { grid-row: 1; }
.palace-spacer  { grid-row: 2; }
.palace-footer  { grid-row: 3; }
```

### 3.1 星曜主体区

所有星曜共用一个从左到右排列的竖列容器。排序仍是主星优先，其后依次为辅星、煞星、杂曜，但不能拆成四个横向区域，否则会与参考图布局不同。

单颗星曜列的内部顺序：

1. 星名，两个或三个汉字由上至下；
2. 亮度，置于星名下方，字号更小；
3. 四化印章，置于亮度下方；
4. 无亮度、无四化时不占空白占位。

推荐 DOM：

```html
<section class="palace-stars">
  <span class="star-column star-column--major">
    <span class="star-name">紫微</span>
    <span class="star-brightness">闲</span>
    <span class="star-transform">科</span>
  </span>
  <span class="star-column star-column--major">
    <span class="star-name">天相</span>
    <span class="star-brightness">旺</span>
  </span>
  <span class="star-column star-column--supporting">右弼……</span>
</section>
```

布局规则：

- `.palace-stars` 使用横向 `flex`，列间距 3–5 px；
- `.star-column` 使用纵向 `flex`，不要直接依赖 `writing-mode`，这样亮度和四化印章可独立控制；
- 中文星名按字符拆为竖排，但无障碍名称仍保留完整星名；
- 星曜过多时允许换成第二排竖列，不能出现宫格横向滚动条；
- 主星字号 15–17 px，其余星曜 12–14 px，亮度 9–10 px；
- 颜色按星曜自身的展示色或五行色，不按“主星/辅星/煞星/杂曜”四类粗暴统一着色；
- DTO 应提供稳定的 `display_tone` 或星曜枚举，组件不得靠中文星名写条件分支。

同宫多颗主星保留后端返回的安星顺序。前端不能按星名排序，也不能根据颜色判断星类。

### 3.2 星曜、亮度与四化

一个星曜竖列是不可拆散的显示单元：

```text
紫　天
微　相
闲　旺
科
```

规则：

- 星名始终显示；
- 亮度位于星名正下方，取值为庙、旺、得、利、平、不、陷、闲；
- 后端亮度为 `null` 时显示“—”或不显示亮度，不得代填“平”；
- 四化用独立印章显示：禄、权、科、忌；
- 四化印章不能只靠颜色，印章内必须保留文字；
- 星曜换行时，整条竖列作为整体换行。

建议颜色：

| 标记 | 颜色 | 说明 |
| --- | --- | --- |
| 化禄 | `#26845B` | 绿色印章 |
| 化权 | `#3267B2` | 蓝色印章 |
| 化科 | `#7651A8` | 紫色印章 |
| 化忌 | `#B33A3A` | 红色印章 |
| 庙旺 | `#8C6428` | 只作为次要文字，不压过星名 |
| 落陷 | `#9A3E38` | 只作为次要文字，不等同四化忌 |

### 3.3 神煞辅助区

参考图的左下角固定显示三行神煞简称，不显示“博士：”“岁前：”等字段标签：

```text
力士
华盖
官符
```

三行字段顺序固定为：

1. 博士十二神；
2. 将前十二神；
3. 岁前十二神。

第一行可使用青绿色强调，后两行使用中性灰。十二长生不出现在参考图宫格左下角，应放入宫位详情，不要硬塞成第四行。

### 3.4 运限区

参考图的大限年龄不是独立横带，而是在右下宫位块第一行，以小号灰字显示：

```text
12–21　壬辰
　　　 兄弟宫
```

当前大限宫在年龄后增加方向箭头或强调色，例如 `22–31↗`。流年、小限等附加状态采用紧凑角标，但不得另建一条横向“运限区”。

同宫出现多个状态时，角标在宫名块附近并排：

```text
〔限〕〔年〕〔小〕
```

不允许后一层覆盖前一层。

### 3.5 宫位页脚

页脚永远贴住宫格底部，使用左右两栏：

- 左栏：三行神煞，依次为博士十二神、将前、岁前；
- 右栏第一行：大限年龄在左，宫干支在右；
- 右栏第二行：宫名使用红色，靠右对齐；
- 命宫在宫名后加“·命”，身宫加“·身”；命身同宫显示“命宫·命·身”；
- 当前大限宫可给宫名块增加浅红描边圆角底，不改变其他宫位的位置。

宫名使用完整名称，不能为了省空间删掉“宫”字。算法索引不得出现在普通界面。

## 4. 中央命盘资料区

中央四格合并后，分为标题、命盘资料、时间说明、图例四部分：

```text
┌────────────────────────────────┐
│           ZHOUYILAB            │
│          阴女 · 水二局          │
│                                │
│ 公历 1996-09-12 06:00          │
│ 农历 丙子年七月三十卯时         │
│ 四柱 丙子 丁酉 壬子 癸卯        │
│                                │
│ 命主 武曲　身主 火星            │
│ 命宫 巳　　身宫 亥              │
│                                │
│ 未提供出生地，按输入时间排盘      │
│ 当前：辛卯大限 22–31虚岁         │
│                                │
│ 四化：禄　权　科　忌             │
└────────────────────────────────┘
```

必须显示：

- 阴阳性别；
- 五行局；
- 公历、农历和时辰；
- 四柱；
- 命主、身主；
- 命宫、身宫；
- 时间口径；
- 当前运限；
- 四化图例。

可选显示：

- 真太阳时校正前后；
- 当前亮度流派；
- 当前魁钺起例。

若未提供 `location`，只显示“按输入时间排盘”，不计算、不展示伪造的真太阳时。

## 5. 空宫设计

空宫不能显示成空白或“无数据”。宫格主体显示：

```text
空宫
借对宫：太阳、天梁
```

规则：

- “空宫”使用中性虚线框；
- 借入星曜用较浅颜色并加“借”标记；
- 借星不能进入本宫 `zhu_xing` 数组；
- 点击借星时跳到对宫或高亮对宫；
- 分析时可使用借星结构，但界面必须让读者分清实星和借星。

## 6. 十二宫选中与三方四正

点击一个宫位后，盘面同时标出四个宫：

| 关系 | 边框 | 背景 | 标记 |
| --- | --- | --- | --- |
| 本宫 | 3 px 实线 | 轻金色 | 本宫 |
| 对宫 | 2 px 实线 | 轻蓝色 | 对宫 |
| 三合宫一 | 2 px 虚线 | 轻绿色 | 三合 |
| 三合宫二 | 2 px 虚线 | 轻绿色 | 三合 |

例如选择命宫后，盘内不画穿过文字的连线，只高亮对应宫格。需要展示关系线时，使用位于宫格下方的独立 SVG 层，且默认关闭。

### 6.1 选宫状态

```ts
interface PalaceSelection {
  selectedBranch: number;
  oppositeBranch: number;
  triadBranches: [number, number];
}
```

对宫和三合关系由后端或公共干支关系模块提供，页面组件不散落 `% 12` 推算。

## 7. 宫格交互

- 单击：选中宫位并高亮三方四正；
- 双击或“详情”按钮：打开完整宫位抽屉；
- 点击四化：显示该化星的来源宫干、所入宫位及路径；
- 点击空宫借星：定位对宫；
- 悬停星曜：显示星类、亮度、四化和资料口径；
- 方向键：按方盘视觉方向移动焦点；
- Enter：选宫；
- Esc：清除选中状态或关闭详情。

宫位按钮的无障碍名称示例：

```text
命宫，巳宫，主星天梁，身宫不在此宫，当前选中
```

辅星：禄存〔庙〕

## 9. 尺寸规范

### 9.1 桌面标准盘

- 整盘：640×640 px，允许在 560–760 px 间缩放；
- 外围宫格：宽、高各为整盘的 25%；
- 中宫：整盘的 50%×50%；
- 宫格内边距：8–10 px；
- 宫格最小点击区域：44×44 px；
- 边框：1 px；选中宫 3 px；
- 星曜行间距：1.25–1.4。

### 9.2 紧凑盘

当整盘宽度小于 520 px：

- 只显示主星、四化、宫干支、宫名、命身与当前运限角标；
- 辅煞显示为数量摘要，如“辅2·煞1”；
- 杂曜和神煞移入详情抽屉；
- 中宫只保留五行局、四柱、命身、当前运限；
- 不把方盘改成长列表。

## 13. 十二宫盘验收标准

1. 子丑寅卯辰巳午未申酉戌亥的位置与固定方盘一致；
2. 页面无论收到何种数组顺序，都能按 `branch_index` 正确落宫；
3. 每宫主星、辅星、煞星、杂曜分类与后端完全一致；
4. 亮度为 `null` 时不显示成“平”；
5. 四化有文字印章，不能只靠颜色；
6. 命、身、限、年、小等角标同宫时不会互相遮挡；
7. 空宫能显示借星来源，但借星不冒充实星；
8. 点击任一宫，能正确高亮本宫、对宫和两个三合宫；
