## 一致性边界

“一致”指相同公历日期、时辰和性别输入下，下列命盘结构一致：

1. 农历年月日与生年干支；
2. 命宫、身宫及五行局；
3. 十二宫宫干、宫支与宫名次序；
4. 十四主星落宫；
5. 参考核心有亮度定义的二十星（十四主星及昌曲、火铃、羊陀）在十二地支的
   完整亮度表（20 × 12，共 240 格）；
6. 左辅、右弼、文昌、文曲、天魁、天钺、禄存、天马和六煞落宫；
7. 生年禄、权、科、忌，包括会四化的辅曜；
8. 空宫、对宫及借入主星；
9. 十二步大限起止年龄与行运方向。

ZhouYiLab 与上游排盘核心 `iztro` 的亮度表均采用“庙、旺、得、利、平、陷、不”
七级口径；但须以资料对应版本逐格核验，不能以名称相同即视为全部一致。当前复取的
iztro 公开亮度表与项目 `BrightnessSchool::Iztro` 在太阳酉宫（公开“陷”、项目“平”）
及七杀酉宫（公开“庙”、项目“旺”）存在差异，已登记在“十四主星亮度对照”，待确认
上游版本后再决定是否调整排盘口径。擎羊、陀罗表中未定庙旺的宫位统一按“平”输出，
对应参考页面的普通档。参考项目自己的页面再将七级亮度归并为
`bright / normal / dim` 三档展示；这是展示层转换，不改变底层亮度。ZhouYiLab 还保留
岁前、将前、长生、博士及更多杂曜，因此完整星表允许出现上游未展示的附加项。

项目另有 `LiangDu::XianYao`（“闲”）作为 Metis 混合亮度表的扩展档；它不属于上述
七级基线。对照 iztro 或其他七级资料时，必须输出亮度表版本并将“闲”保留为扩展值，
不得静默归并为“平”或声称该格已与七级表逐格相同。

## 固定随机案例

示例使用线性同余生成器和固定种子 `20260911`。两端依次抽取年、月、日、时支、
性别，得到：

| 字段 | 结果 |
| --- | --- |
| 公历 | 1991-02-21 |
| 时辰 | 亥时（ZhouYiLab 取代表钟点 22 时） |
| 性别 | 女 |
| 农历 | 辛未年正月初七 |
| 命宫 / 身宫 | 卯 / 丑 |
| 五行局 | 木三局 |
| 紫微 | 午宫 |

运行 `example_zi_wei` 时会重新生成此案例，并逐项核验农历、命身宫、五行局、
十四主星、二十星完整亮度表、辛年四化、空宫借星和十二大限。任一核心项目不一致，
示例会以失败退出，不会继续生成一份看似正常的报告。

## 不在本次对齐范围的上游功能

上游 README 已明确说明 AI 解读提示词、后端 API、用户系统与支付系统没有开源；
这些能力没有可复现实现，不能用静态文案冒充已经对齐。ZhouYiLab 当前对齐的是
可在本地独立验证的紫微排盘与结构分析能力。
