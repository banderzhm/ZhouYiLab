# 梅花易数排盘后如何分析

## 一、起卦口径

梅花易数以象数起卦，不沿用纳甲六爻的装卦、六亲、世应和月破体系。本项目支持五种法门：

1. 年月日时起卦：年取地支数，子一、丑二，顺至亥十二；月、日取农历数；时仍取地支数。
2. 两数起卦：第一数除八取上卦，第二数除八取下卦，两数相加除六取动爻。
3. 三数起卦：前两数分别取上、下卦，第三数除六专取动爻。
4. 字占笔画起卦：调用方按选定字书口径给出上下字组的繁体笔画合数，分别取上、下卦；未另给动数时，两组笔画相加取动爻。程序不暗自判定异体字笔画。
5. 闻声起卦：连续可辨的声数取上卦，声数加时支序数取下卦并定动爻。

余数为零时，八卦按八论，六爻按六论。时间起卦若提供地点，先校正真太阳时，再换算农历年月日与时支；未提供地点时径用输入时刻。农历闰月保留“闰”标记，取数仍按该月月序，不把闰月另增为第十三月。

## 三、体用分判

动爻所在的经卦为用，未动的经卦为体：

- 初、二、三爻动：下卦为用，上卦为体；
- 四、五、上爻动：上卦为用，下卦为体。

体主己身、根本与承受者；用主所占之事、对方及外来作用。体用不能只输出五行名称，必须明确谁生谁、谁克谁：

| 体用作用 | 基本卦意 |
|---|---|
| 用生体 | 外来生扶，所占得助 |
| 体用比和 | 内外同气，谋为易合 |
| 体克用 | 所占受我节制，可成而较劳 |
| 体生用 | 体气外泄，先付出后见事 |
| 用克体 | 外事制身，宜守不宜强进 |

## 四、本卦、互卦、变卦

- 本卦主事情初始、眼前格局；
- 互卦由二三四爻为下互、三四五爻为上互，主中程转折与内在过程；
- 变卦由动爻阴阳反转而成，主动后归宿。

分析时以本卦用卦为第一层，再看互卦上下卦分别对体卦生克，最后看变卦中动位之经卦对体卦的终局作用。不能只列三个卦名而不完成这条体用链。

## 五、月令旺衰与体党用党

时间卦以农历月令校正八卦五行气势：寅卯木旺，巳午火旺，申酉金旺，亥子水旺，辰未戌丑土旺。旺、相、休、囚、死不仅展示在报告中，还参与诸卦有效卦力：旺 1.50、相 1.25、休 0.90、囚 0.65、死 0.45。互卦主中程，阶段系数为 0.65；本卦和变卦各按 1.00。

体卦自身为体党根本；比和、来生体者归体党；克体、泄体或受体所制者归用党。这里的“用党”是外事一方的力量归属，并不等于一概为凶。体党、用党分别汇总有效卦力，作为本互变生克之后的第二层校正：体党得势主承应较足，用党得势主外局牵制或所占对象较强；两党接近时，以动爻、外应和占问门类定夺。

数字卦没有月令输入时，不伪造旺衰结论，报告应明确标为“未定”。

## 六、动爻与万物类象

动爻既定体用，也说明事情发动的层次：初爻为事机初萌，上爻为物极将变，三爻处内外交界，五爻为成败枢纽。八卦自然、人伦、身体、方位诸象须结合占问门类落断，不得用一条固定文案覆盖不同门类。当前二十门策略分别为泛占、功名、求财、婚恋、疾病、出行、学业、失物、天时、人事、家宅、屋舍、生产、饮食、求谋、交易、行人、谒见、官讼、坟墓；每门独立规定体用落点、可取之象、阻滞之象与专断，不以标题替换冒充策略分流。

起卦当下所得声音、人物、动物、器物、天候和方位可作为外应。外应先归八卦或先天数，再辨其对体卦的生克；无法可靠归象时只保留所见所闻，不强造卦象。外应只参验主卦，不反向覆盖本互变主链。

## 七、应期

应期按候选而非唯一日期输出，依次参看：

1. 动爻数；
2. 用卦先天数与用卦方位；
3. 变卦先天数与变卦方位；
4. 体卦得令、得生之时；
5. 体、用、上下互卦及变用的先天数合计，作为全卦约期。

事情近而动者可取时、日，事情远而静者可取月、年。占问输入可明定即时、近日、中程、久远；未明定时，内卦动主近、外卦动主远，再以用卦旺相或休囚校正单位。程序输出有序候选和触发条件，不伪造唯一公历日期。

## 八、卦势判定

总断不得只给“大吉、吉、平、有阻、凶”而隐去算法。每项卦力按“生克基础值 × 月令气势系数 × 阶段系数”计算：用生体为 3、比和为 2、体克用为 1、体生用为 −1、用克体为 −3；本用与变用阶段系数为 2.00，上下互卦各为 0.65。最后增加“体党卦力减用党卦力”的八成校正。

报告必须列出每一项的职责、生克、旺衰、三个系数、本项卦力、党势校正及综合卦势值。上述数值属于项目规则化口径，必须携带规则版本，不冒充古籍原有固定分数。

## 九、输出契约

正式报告必须依次给出：起卦法门与原始象数、上下卦及动爻合数、本互变三卦、体用分判、互变生克、月令旺衰、体党用党、动爻取象、万物类象、分门占断、外应参断、占断依据、卦势判定、五项应期候选、总断与参看事项。JSON 与中文文本共享同一份分析结果，不在展示层重新推演。
