## 基础规则归属

- 先搜索 `src/common/tian_gan/{ganzhi,wu_xing_utils,ba_zi_base}.{cppm,cpp}`、`src/common/time/`、`src/common/tyme/` 和 `src/common/yi_jing/` 的现有定义，不得在分析器重复定义五行、十神、藏干、刑冲合害、三合三会等基础表。
- 通用干支关系及人元司令基础归 GanZhi；五行与纳音五行等归现有五行基础职责；四柱组合基础归 BaZiBase。先核对现有 API 和调用方，不能另写中文后缀解析推回枚举的替代算法。
- 关系检测与流派判断分开：检出六合、半合、拱合不等于成化；方向性相刑不等于对称冲害；同支、同柱、自刑、岁运并临必须各按条件判断。复合关系可并存，不能用单值覆盖其他成立关系。
- 跨原局、大运、流年组合使用带来源和宫位的参与项，保留所缺中神、补齐位置、旬空与引动方式。两两扫描不能替代三支补齐检测；规则去重键应包含关系、参与位置与层次，不能仅按显示文字去重。

## 流派与推演口径

- 八字分析按 `src/ba_zi/analysis/ziping/` 与 `mangpai/` 分包，统一入口只分派，不把某流派结果硬塞进另一流派的契约。
- 子平区分格局取用、调候状态、具体天干透藏根气、喜忌角色及岁运作用；同五行异十神不得自动等同，分数需有规则、分母、权重和作用来源。
- 盲派岁运使用“岁运引动—宾主变化—做功链变化—宫位取象—应事类型”，不复用子平扶抑评分与喜忌模型。宾主是宫位轴、体用是作用轴；不能因宾位就排除体，或将主位财官改成宾位。
- 六爻按世应、动变、用神和月日作用；大六壬按天地盘、四课、三传及年命；奇门按宫门星神仪及占问；梅花按体用、互变与动爻。只复用基础关系，不迁移另一术数的判断模型。
- 流派分歧写成明确口径/配置与待辨条件；不可仅凭少量个人经历反向调权重使结果命中，也不可将术数报告描述成已证实的医学、财务风险预测。

## 时间与地点

- `location` 可选：未提供时直接使用传入时间，不隐式补地点、不计算真太阳时。有地点时统一调用现有时间模块，不在各术数各写一套修正。
- 民用时间、时区、农历/公历、节气边界、子时换日以及修正后跨日必须区分。保留输入时间、实际排盘时间和修正依据，避免重复修正。
- 纬度、经度按 API 的真实用途使用，不凭空给纬度附加真太阳时修正。人元司令等依赖节气经过时间的规则必须接收准确时间上下文，缺失时注明不能判定，不能以月支本气冒充司令。
